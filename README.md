## 📌 Featured Project

### Exam Management System (EMS) & Safe Exam Browser
A computer-based assessment platform being built for the Addis Ababa University
Computer Science Department, as part of the 2026 Summer Internship Program.
It replaces the department's current Google Forms mock exit exam with a
proper exam delivery system, and adds a Windows lockdown client (Safe Exam
Browser) so the mock exam can realistically rehearse the locked-down
conditions of the real national exit exam.

**Technologies:** Node.js · Prisma · PostgreSQL (Neon) · Socket.IO (WebSocket) · JWT/OTP Auth

**Key Areas:**
- 📝 Instructor question-bank authoring and exam scheduling
- 🖥️ Student exam delivery portal with real-time timer and autosave
- 🔒 Windows Safe Exam Browser (SEB) lockdown client
- ⚡ Server-authoritative session state (timer, submission, violations — never trusted from the client)
- 🎯 Auto-grading for objective questions, manual grading workflow for open-ended ones
- 📊 Result reporting and exit-exam-style performance summaries
